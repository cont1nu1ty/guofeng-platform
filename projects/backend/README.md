# 家风中华行 · 后台建设项目

立项日期：2026-09-21。最新状态：**后台界面v0.1已实现并可在5174预览；Java后台、真实数据加载/存储与身份权限尚未接入**。

本项目根据已有《小程序制做要求.pdf》需求基线，为全国管理、区域运营和专家评审建设统一后台。最新用户要求优先实现界面，数据加载和存储暂不考虑；因此先落地 [apps/admin](../../apps/admin/README.md) 的13个页面与内存交互，后续真实接入计划保留。5173上的Uni-app用户端继续使用。

**建议主线：RuoYi-Vue-Plus + 配套 plus-ui Vue 管理端 + 自带 WarmFlow；保留现有 Uni-app 用户端。** 先复用基础管理，再实现“投稿 → 后台初审 → 专家评审 → 结果发布”。选择 Spring Boot 模块化应用，AI/OCR 在后续独立服务中接入。

首轮先完成底座兼容性验证与真实投稿/退修闭环。若已确认需要 BPMN 或近期完整商城，再整体转用芋道体系；不同时维护两套账号、权限和工作流。默认分支与最新发行版只作为调查证据，经过构建、权限、文件和流程验证后才成为采用版本。

现有页面的身份切换、地区筛选、演示评分与本机证书不迁移成正式业务数据。原文六级流程、省级物理分库、私有 AI 和全国容量仍有独立开发及验收要求。

本目录是后台立项入口，归属现有仓库；独立管理站已在`apps/admin`，实际复用Element Plus及plus-ui两项裁剪组件，来源见根`source-lock.json`。`apps/server`与数据库尚未建设；后续按 [整合计划](delivery-plan.md) 接入并保留上游许可证、精确版本与升级路径。
