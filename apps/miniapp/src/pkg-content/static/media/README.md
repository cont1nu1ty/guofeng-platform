# 原创前端演示媒体

`family-letter`、`everyday-values`、`integrity-talk` 三组 JPEG/MP4 由项目脚本 `scripts/generate_demo_media.py` 原创制作，每条为 12 秒、640 × 360、H.264、无音轨的文字动画。文字、图形、排版均为本项目新建；不包含第三方视频、照片、人物录音或 AI 生成素材。

播放页明确标注原创静音样片。`integrity-talk` 演示回放布局，不是实际直播录制。

图像通过本机 Noto Serif CJK / Noto Sans CJK 渲染（SIL Open Font License 1.1）；字体文件没有嵌入或复制进这些媒体。字体项目来源：https://github.com/notofonts/noto-cjk 。视频及封面属于本项目的原创演示资产，可随本项目修改、分发与用于演示。

重新生成：安装 Python 3、Pillow 和 FFmpeg；调整脚本中的本机 Noto CJK 路径，然后运行 `python3 scripts/generate_demo_media.py`。

名人馆不使用外部图片：展厅、书册与人物名印由 CSS 原创绘制。人物介绍基于以下公开资料的简短摘要；除公版古文短句外，未复制资料正文。颜之推页“重实学，涉世务”为主题概括，不标为古文原句。

- 诸葛亮《诫子书》：https://www.ccdi.gov.cn/lswhn/wenhua/wenyuan/201810/t20181031_27023.html
- 颜之推《颜氏家训》：https://zgjjjc.ccdi.gov.cn/bqml/bqxx/201603/t20160331_76976.html
