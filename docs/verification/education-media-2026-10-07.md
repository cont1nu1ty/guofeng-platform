# 教育、普通媒体与HTTP文案核验（2026-10-07）

本记录仅覆盖本轮教育与普通媒体工作包。运行环境为本机独立 Compose 项目 `jiafeng-demo-non-ai-check`，HTTP `127.0.0.1:19084`；测试显式设置 `JIAFENG_ISOLATED_TEST=1`。未对原有运行项目写业务数据；未部署正式微信小程序。账号、课程、干部申请、承诺、短片及全景图均为合成验收资料，不代表真实业务资质、学时、录音或展馆实景。

## 已实现并接入

- 教育后台：章节及稳定编号、单选题库与组卷、测验阈值；保存草稿与发布版本分离。已发布快照不可变，学员不接收正确答案和内部解析。旧元数据编辑保留题库。
- 学习：按课程版本主动确认章节，服务器校验题目/选项并判分，允许重试并保留最佳成绩。阅读确认不计真实学时；新发布版本不继承旧版本结业记录。
- 班组：成员分配固定课程版本和地区；干部身份经管理员人工审核；成员对承诺文本和摘要主动确认，保存各版文本、时间与摘要，具备个人历史及后台台账。它是确认记录，非电子签章。
- 教育后台课程、班组、身份申请使用SQL地区筛选及独立20条分页；成员候选按姓名或完整账号ID查询、最多50个候选。本人学习历史、个人承诺及单班组版本史仍会累积，不据此宣称全站所有列表均完成分页。
- 普通视频：上传MP4/MOV/WebM后由服务器本地ffprobe/ffmpeg解码并归一为H264/AAC MP4，限制单画面、10分钟、上传及输出50MiB、尺寸、并发槽和处理时限；保留源文件摘要及归一文件摘要。
- 人工字幕和人工朗读：独立草稿/发布/下架，时间轴不重叠，朗读关联编辑本人上传的媒体音频。公开接口需主媒体已发布，且字幕绑定的源文件仍一致；更换主视频后旧字幕隐藏，编辑确认后才能重新发布。
- 全景：使用管理员提供的HTTPS 2:1等距柱状图片，在H5 WebGL中提供球面拖动、方向、缩放及重置。非H5明确显示平面全景，不宣称微信球面完成。缺图、跨域或WebGL失败有提示和平面回退。
- HTTP界面：修正个人中心、典籍摘录、文创记录的英文“仅本机”误述，保留demo模式的真实设备存储说明。增加站内日/周摘要及草稿提醒个人偏好；隐私说明解释登录访问和分享意向按日去重，复制链接不代表实际转发。
