## 尚未完成的验证

- iOS/Android微信手机、平板、异形屏/安全区/软键盘的完整矩阵；编辑器选区、相册权限、录音、文件访问、缓存配额/断网及竖排。
- 新版字体在手机上的实际成功加载与生僻字回退；2.10.0基础库目标和当前字体3.7.9+条件的决策/兼容验证。
- 全量中英页面、空错态、通知、公示和证书；读屏/焦点/点击区域/大字覆盖。
- 明确定义后的手机首屏<1.5秒/60fps、正式代码包上传与分享接收端落地验证。
- 正式微信/实名、公网部署、本地模型与AI质量、全国容量与生产运维验收；本轮只覆盖明确记录的本机真实业务、权限和恢复场景。
