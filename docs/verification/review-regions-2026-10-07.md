# 评审、线下归集、地区与咨询验收（2026-10-07）

本记录只覆盖本次评审与地区咨询包。运行验证使用独立的 `jiafeng-demo-non-ai-*` Compose 项目、测试账号和测试数据，不修改原部署。浏览器与完整构建结果由同日总验收记录另列；编译或 HTTP 探针不代替微信真机、地图公网可达性、定位授权或容量验收。

## 实现边界

- 稿件提交、退修重投和线下归集时，修订版绑定不可变的六节点流程与各节点量表；修改全局配置只影响后续修订版。既有 `jiafeng-four-v1` 保留原四维；新任务从绑定节点获得维度、分值与规则版本。节点总分必须为 100 分。
- 作者进度从 WarmFlow 实际任务和办理记录投影，展示六节点、当前阶段、办理记录、评分标准和历史版本；隐藏专家身份与内部办理信息。历史版本缺少配置或办理证据时明确显示未知，不根据最终状态倒推完成记录。
- 自动分配先预览、后确认。地区、专家账号身份、接单状态和可选分组先过滤，再按有效待评分数和专家编号确定选择。确认重查稿件版本和预览摘要，复用原分配与匿名评审流程；仍由管理员人工决定和发布结果。
- 线下导入支持有来源名称、来源编号和已有投稿账号的 CSV 文字稿件，每批 1–100 条。预检不写业务数据，确认以来源去重。归集不代替本人同意：初审前必须由所属账号核对正文并确认投稿须知；确认记录追加保存，原修订正文及版权状态不回写。
- 地区目录支持现有省级字典下的市、区县维护、来源记录与启停；没有预置或推断全国完整市县数据。阵地可关联同省启用节点；地区目录不改变省级账号授权。停用父节点隐藏整个下级树，草稿阵地不进入公开地区筛选。
- 地图坐标系须由运营依据来源核对。H5 对明确标记 WGS84 的阵地提供用户主动加载的 OpenStreetMap 官方 iframe，保留原提供方署名，并说明第三方接收网络地址；不发送用户定位。小程序地图仅使用明确 GCJ02 坐标；未知坐标系保留地址及既有导航入口。附近距离仅比较经确认 WGS84 坐标，设备定位只留本次页面内存。
- 定制咨询与公益发放分开。管理员追加用户可见沟通和人民币参考报价，记录历史并发站内消息；申请人只能看本人记录，已取消咨询拒绝后续操作。此包不创建付款、商业订单、合同或物流，不扣公益库存。
