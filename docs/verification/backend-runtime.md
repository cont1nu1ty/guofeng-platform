## 真实业务接口

可重跑入口：`python3 deploy/tests/business_probe.py`。脚本读取 Git 忽略的本地配置，使用六个真实开发账号，创建带「验收」前缀的记录；不清库、不删除卷，不输出密码/令牌。会临时调整试点流程并恢复、临时停用测试账号并重新启用；运行时不要同时编辑这些测试账号和流程设置。

[业务结果 JSON](previews/backend-2026-09-26/business-probe.json) 记录实际检查、验收稿件 ID 和文件 SHA-256。

本轮最终脚本 **32 组检查全部通过**。已覆盖：

- 六账号登录、失效令牌401、停用专家不能接单且不误使运营退出；会员后台拒绝，专家运营命令拒绝；本人、跨人、两地区列表/详情/修改/附件边界。
- 云草稿 ETag、缺版本和旧版本拒绝；提交确认后匹配草稿清空，不误删另一窗口的新草稿。
- 幂等提交、同键不同载荷冲突、同键并发只生成一稿；退修重投保留作品 ID、原稿正文和版本。
- 中文文件名、multipart 上传、伪装类型拒绝、超过 10MiB 拒绝、真实 S3 字节读取，跨人和专家原附件拒绝。
- WarmFlow 实际定义/实例/任务推进，运营确认匿名材料，四维 30/30/25/15 范围，未分配账号拒绝、重复评分拒绝、任务到期拒绝、重新分配后旧任务失效。
- 配置更改后旧实例保持原流程；评分不自动发布；人工结果、公开发布和撤回独立，已公开稿改为未入围时撤销公开。
- 资讯草稿/发布/下架、典籍入藏与编辑撤回；活动并发末位名额、取消、重报名、重复报名与签到；签到时间单独记录，不再用报名时间代替。
- 课程简介编辑同步到实际发布的导读章节，实际章节学习和完成记录；公益单次额度、幂等申领/发放、并发库存不超发、跨地区申领归商品履约运营管理。
- 区域站内消息发送与已读；停用账号令已有会话不可用且可重新启用。

此次真实并发验证曾发现默认可重复读快照导致活动超额，已改为 READ COMMITTED 配合账户/业务行锁并重验。独立审查发现并修复提交后旧草稿残留、结果撤销仍公开、跨区发放修改他区库存；相关用例已纳入脚本。不能把修复前的试跑日志当作通过证据。

另运行 `python3 deploy/tests/workflow_probe.py`，实际验证默认六级流程从收件初审、五次专家办理至完成，以及禁用前五节点时直接进入末节点。未完成流程不能人工决定，完成后也不会自动公开；测试后恢复原配置。[流程证据](previews/backend-2026-09-26/workflow-probe.json)

- V001 业务迁移及六个开发账号正常创建，原若依示例登录账号禁用；重复启动校验迁移 checksum。
- V002 为历史版本附件建立外键关联并回填。既有 V1 数据升级 V2 后，稿件和文件仍存在。
