# v0.1 演示范围与沟通顺序

本次交付建立代码项目、整理需求、验证开源复用路线，同时完成一组可操作界面。界面中的文章、作者、典籍和活动均为演示，不代表官方发布或真实招募。

## 推荐 8 分钟演示

1. **首页**：介绍主视觉、八个入口与“全国站”；选择北京/浙江/四川，观察作品内容变化。尚未实现的短视频、名人馆、商城显示规划说明。
2. **投稿**：选通道和体裁，输入标题及至少 20 字正文；离开再回来检查草稿。空内容提交会显示校验，勾选须知后可生成演示编号。
3. **个人中心 / 评审公示**：查看刚才的投稿，在进度页点击最近一次投稿或输入编号；查看拟定六级路径。可用 `DEMO-WORK-003` 查看中间节点示例。
4. **典藏**：搜索和筛选作品；阅读示例篇章，切换竖排/横排及大字；收藏后在个人中心查看。
5. **传习**：预约一个样例活动，检查人数和我的预约，随后取消。操作不触发真实报名。
6. **AI 家风助手**：输入问题，查看预设回答与创作结构。这只是交互示例，没有调用外部模型。
7. **运营视图**：查看当前地区样例列表及本机数据统计。它是只读沟通界面，不是带权限的后台。

## 演示数据与边界

- 收藏、草稿、投稿及报名使用 `jiafeng:demo:v1` 存储键。刷新后保留；清理站点存储会清空本机操作。当前没有重置按钮，避免演示中误清空草稿。
- 地区、搜索词和大字偏好是会话内状态；刷新回首页及全国视图是当前预期行为。
- 首页搜索只查当前地区作品、当前地区/全国典籍与当前地区活动；活动结果进入活动列表。
- 原型允许公开查看样例进度和只读运营界面；正式版本必须实施登录、作品归属、公开发布状态和租户权限校验。
- 六级节点取自“内部讨论稿”，不代表正式评审制度或机构授权。
- 大字模式主要放大正文、表单和阅读内容；不是完整无障碍认证，也没有实现全部字号比例设置。
- 当前 CSS 插画为原创图形，中文字体使用设备已有字体；不同设备的宋体效果会有差别。
