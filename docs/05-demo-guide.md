# 前端展示版 · 演示范围与操作

本轮实现前端展示与本机交互。投稿、评分、授奖、预约、证书与文创记录均不产生真实业务效力。原 PDF 是需求输入，正式服务仍按后续待办推进。

## 推荐演示顺序

1. **首页**：切换轮播，查看公告、八个入口、四大专题与示例统计；选择地区和语言。资讯有分类、专题与详情，详情可返回。
2. **投稿**：选择通道/体裁/最多3个主题，填写标题和正文，使用段落辅助；选择图片、PDF或Word（最多5个、单件10MB）。预览附件元信息和正文，阅读并勾选须知后，在最终预览中模拟提交。
3. **完整评审**：在个人中心打开作品进度；进入模拟专家工作台，填写三项评分和意见，退回修改；回个人中心修改重投，原编号与历史意见保留、版本递增。继续逐级晋级，在第六级确认入围，再模拟授奖与入藏。查看公示、消息和模拟证书。
4. **典藏**：按总卷/地方卷、体裁、主题或关键词筛选，进入典籍/作品原生详情，使用目录与上一章/下一章。切换横竖排及大字，收藏；选取段落、填写感想后保存，在个人中心恢复摘抄或更新同段感想。查看原创词义解释与版权说明；H5 下载本篇 TXT，微信端复制文字。
5. **清廉课堂**：逐节阅读，完成情景测验；全部完成后预览结业证书，个人中心显示学习记录。
6. **传习与场馆**：查看活动详情并模拟预约、签到和参与证书；从示意地图进入场馆导览及关联活动。取消预约同步清除签到和对应证书。
7. **视频与名人馆**：播放原创静音样片、查看回放布局、点赞/收藏；人物馆展示注明来源的介绍和普通场景热点，可保存家训卡。没有真实直播或VR。
8. **文创**：从商品详情进入公益申领或定制咨询；完成表单后到个人中心查看或取消本机记录，没有支付或真实订单。
9. **创作助手**：切换家书起草、家训拟写、文稿润色、手稿校对、使用帮助五种模式，选择不同预设并查看结果。手稿校对通过页面样卡和待校文本手工对照，创作结果可改写、复制和存档。尝试“转入新投稿草稿”，检查已有普通草稿的保留/替换选择，以及退回修改稿的保护提示；帮助回答不能转为作品。
10. **个人中心**：切换投稿状态、收藏、学习活动、消息、证书、文创、创作存档和设置。恢复摘抄感想、家训卡和助手示例；检查语言、大字、隐私说明及两套字体的实际加载状态。

### 阅读与创作工具的展示边界

- 典籍章节为原创演示选读，词义面板为原创编辑注解，不是经校勘的古籍原文、权威辞书或 AI 实时解释。正文和导出文本均注明样例及使用范围，正式内容仍需版权与出版审核。
- 竖排从右向左阅读，可横向滑动；H5 已检查布局，微信端的竖排、字体和真实设备操作仍待专项验证。选取多个段落后保存一条摘抄，同一来源与相同文本再次保存会更新感想；这些记录只在本机。
- H5 的“下载本篇 TXT”生成真实文本下载请求，包含完整演示篇章和使用说明；是否保存到磁盘由浏览器控制。微信端按钮为“复制本篇文字”，不宣称生成 PDF、完成文件下载或获得正式出版物。
- H5 朗读仅调用浏览器提供、匹配当前中英文语言的本机声音；无可用声音、启动失败或播放错误均有反馈。支持语音时可开始、暂停、继续和停止；切换章节、语言或离开页面会停止。微信端未接入音源，显示图文阅读导引。当前浏览器环境已检查无本机语音时的提示，控制流程另用模拟语音接口检查，不能据此声称已验收真实发声、方言合成或真机音频。
- 助手全部结果来自五类本地预设文本。修改输入后仍只展示所选预设，页面明确提醒不会处理新输入；润色展示预设原文对照，手稿样卡由页面文字排版，未上传图片、识别手写内容或执行 OCR。用户可手工改写结果；查看预设没有模型等待过程。
- 复制仅写入剪贴板；“保存示例”才创建本机存档。存档保存所选预设的输入与当前编辑结果，可从个人中心恢复，不会把自填输入伪称为生成来源。
- 转入投稿先检查现有草稿：无草稿时创建新稿；有普通草稿时默认保留，只有明确选择替换才写入；带原作品编号的退回修改稿始终受到保护，可另存助手示例。新稿不携带原作品编号、附件或版权勾选，不自动提交；存储失败不继续跳转或改动原草稿。

## 状态、导航与存储

- 首页和详情分别使用 Uni-app 页面；一级栏目切换用 reLaunch，详情用 navigateTo，返回用 navigateBack。正常详情返回保留原列表筛选和位置。浏览器手工修改同一路径参数后需刷新。
- `jiafeng:demo:v1` 保存草稿、投稿、评审、消息、作品证书、收藏与预约；兼容旧版缺省字段，未清理已有数据。
- 课程/签到、视频/文创、创作存档和语言使用各自模块存储。它们均属于当前设备，无云同步。不要用清缓存作为常规演示步骤。
- 附件文件只在当前会话中预览，刷新后保留元信息并提示重新选择；没有云端上传，也没有解析Word/PDF正文。
- 本机读取/写入失败会提示；保存失败不推进业务状态。空列表、无结果、无效详情和媒体失败均有反馈。
- 中英切换覆盖主要界面与新增内容模块；用户输入、原始作品正文、历史评语和部分证书内容保留原文，不称为全站内容完整翻译。
- 大字模式侧重正文与阅读，不代表无障碍认证；微信竖排和字体需单独检查，H5截图及编译成功不能替代真机证据。

## 素材与真实性

资讯、篇章、课程、活动、商品均为讨论用原创示例；历史人物简述注明公开参考来源。视频为原创12秒静音文字动画；回放页不是实际直播录像。统计为样例，地图为示意，身份为本机模拟。

本轮保留 Wot UI / Uni-app 复用结构和锁定版本，不新增真实后端、机构账号或第三方AI数据传输。生产功能与验收输入见需求、敏捷待办和后端路线文档。
