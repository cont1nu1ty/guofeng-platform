查看演变：

```bash
git worktree add ../jiafeng-baseline v0.1.0-baseline
```

## 本轮视觉决策

- 主色统一为中国红 `#C41A1A`；品牌、导航激活、横幅与主按钮共用同一色值。
- 墨色 `#2C2C2C` 用于主要文字；次要文字使用更清楚的深灰，古金 `#C9A96E` 主要用于细线、边框与装饰。
- 宣纸米白 `#F5F0E8` 保留为背景，保留书册、印章、竖排与留白。宣传卡片与典籍封面取消绿色分支。
- 中文模式下减少装饰性英文，标题使用实际载入的思源宋体子集 600，正文使用思源黑体子集 400。字体许可、字符范围与微信兼容边界见 `09-fonts.md`。

这些更改保留原有页面骨架，并未采用另一套视觉模板。业务仍通过独立领域仓库与本机数据适配，不在本轮引入真实登录、支付或 AI 服务。
