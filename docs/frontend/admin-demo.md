# 运营后台界面演示

`main` 的空卷 HTTP 环境不预装业务内容；需要下述完整模拟场景时使用 [演示数据分支](https://github.com/cont1nu1ty/guofeng-platform/tree/codex/demo-data-bootstrap) 并按[部署说明](../../deploy/README.md#显式导入演示数据)显式导入。已有前端 Mock 与静态示例资源仍保留。

## 2026-09-30 评审窗口与提醒

HTTP 模式下，在稿件或专家分配入口选择“立即开始”或指定北京时间；留空截止时间使用当前稿件冻结的期限。进入评审管理，通过“调整时间”填写新时间和原因；开始后只可延期。评审预警页可按临期、逾期、权限范围和未读筛选，右上角个人提醒可定位任务。系统设置中的“评审提醒”现控制真实站内自动提醒；关闭后仍显示预警并执行评分窗口校验。参见[完整规则](../engineering/review-windows-cache.md)及[本轮验证](../verification/review-cache-2026-09-30.md)。

Mock 新分配的完整时间窗口会按本机时间限制评分；旧的仅日期样例明确为展示日期，不施加窗口限制。延期与自动预警只由真实 HTTP 服务提供，不在浏览器模拟通知投递。

本文件记录独立 Web 后台的数据模式与操作范围，用户端完成情况另见 [用户端对照](user-status.md)。

## 2026-09-26 · 首页与目录联动

“内容与资讯”新增轮播、媒体、阵地、名人馆、首页栏目和人工咨询工作页签，保留原13个主导航。六类轮播可独立语言、地区、排期和关联目标发布；目录下架会影响用户端。操作、新增模拟场景、文件及服务边界见[目录管理](catalog-management.md)，实际检查见[本轮验证](../verification/catalog-2026-09-26.md)。

## 2026-09-26 · 当前展示数据入口

当前 [后台](http://127.0.0.1:18080/admin/) 与 [网页用户端](http://127.0.0.1:18080/) 已共用“秋日邻里故事”数据集。旧验收数据已备份清理，现有13个账号、16篇稿件、17份修订、51条评审任务历史，以及资讯、典籍、活动、课程、公益和私有资料，均已保存在真实后端，供两端通过 HTTP 共同读取和操作。

先看 [账号与六段演示路线](showcase-data.md)：包含待审/退修/重投、有效与过期评审、人工决定与公开撤回、活动满员/取消/签到、学习完成度和五种申领状态。推荐先用 `devadmin`（全国展示运营）浏览，再换 `region_zj`（沈书宁）、`region_bj`（陆知微）比较地区范围，用 `expert_zj`（顾明川）处理已分配任务。密码只查看本机 `deploy/.env` 的 `JIAFENG_DEV_PASSWORD`。

模拟的是人物和业务情境，保存、权限、文件及两端同步使用真实服务；未接模型的 AI 调用日志保持空态，过期任务可由运营延期或重新分配。演示操作会持久保存，需要恢复初始情形时执行 `./deploy/dev reset-demo`，命令会先备份当前数据。`demo` 模式的内存和设备样例不会自动迁入当前数据库。

## 2026-09-26 · HTTP 服务接入

后台保留现有 13 页视觉，增加真实服务模式与登录入口。Compose 部署地址为 `http://127.0.0.1:18080/admin/`；开发测试账号与本机生成密码见部署说明，不在文档保存密码。`VITE_DATA_MODE=demo` 仍可独立演示；`VITE_DATA_MODE=http` 读取数据库和 S3 业务接口，不回落示例数据。独立联调见 [后台 README](../../apps/admin/README.md)。

| 模块 | HTTP 模式操作 |
| --- | --- |
| 登录与工作空间 | 登录、刷新恢复会话、退出；按服务端权限显示菜单和操作按钮；显示加载、空态、错误及 requestId |
| 投稿与评审 | 初审/退修、原附件授权下载、准备并确认脱敏正文、分配专家、四维评分、流程版本配置、人工决定、公开/撤回发布；管理员查看评分，当前任务专家提交，本期强制匿名评审 |
| 内容、典籍、活动 | 内容编辑与上下架；分卷/章节编辑、排序、导入已公开入选作品与入藏；活动编辑/发布/开始/结束、报名与签到 |
| 用户、教育、公益 | 岗位和账号状态调整、入驻审核；课程管理与学习台账；空库新增文创资源、库存/额度、申领审核与确认发放 |
| AI 运维、系统设置 | 私有文件上传并登记知识资料、词库编辑、实际调用记录；平台配置、通知草稿、明确确认后发送站内消息、操作日志 |
| 工作台与数据 | 汇总当前账号有权访问的记录；按实际日期绘图，没有历史时显示空态；导出授权范围统计 CSV |

推荐联调路径：**登录全国/区域账号 → 用户端提交 → 初审 → 确认脱敏材料 → 分配专家 → 专家账号评分 → 运营按流程继续分配/确认结果 → 另行发布**。同稿件仍有有效待评分任务时不能再次分配；完成、取消或到期后可继续分配，服务端仍验证当前流程节点。内容和活动可从空库创建；发布后用户端读取同一后端。统计不是全国容量或运营指标采集验收。

写请求发送实体 `lockVersion` 与幂等键，成功后才按服务端工作空间更新界面；并发冲突保留编辑表单，网络结果不确定时重试同一操作复用幂等键。业务数据不存入浏览器；独立会话令牌保存在项目专用 sessionStorage key。HTTP 地区选项与服务端完整 35 地区及全国一致；区域运营登录默认首个获准地区，全国管理员默认全国。地区选择只能缩小已授权数据，统计不为未授权地区生成零值行，真正的权限、归属和事务由服务端验证。

文件类型为 PNG/JPEG/PDF/Word、每份 10MB 以内；客户端经后端上传，保存 fileId，下载时换取短时签名 URL。AI 资料上传不代表已建立检索索引，模型、OCR、正式电子签章、微信登录与外部消息推送仍未启用。正式支付、订单与物流也不在本轮界面接入范围。

本轮前端按固定 plus-ui 提交复用 token 生命周期、登录表单流程、Bearer 请求边界和权限匹配，适配为现有界面及直接 DTO；原始快照与改动说明见 [上游记录](../../apps/admin/upstream/plus-ui/README.md)。实际验证按 [后台验证记录](../verification/admin-ui.md) 分开列出合同 fixture 与真实服务证据。

## 后台界面 v0.1 · 历史演示模式

独立工程 `apps/admin`，开发预览 http://localhost:5174/ 。用户端仍在5173，两个应用的示例数据互不读取或同步。后台直接进入演示工作空间，不提供虚假的正式登录/权限流程。

推荐路径：**工作台 → 投稿作品 → 打开待初审稿件 → 通过初审 → 分配专家 → 评审中心打分 → 内容资讯编辑/预览 → 活动管理 → 系统设置操作日志**。

后台所有写操作只修改当前会话内存；刷新或右上角菜单“重置全部示例”后恢复初始样例。浏览器导出CSV会生成真实的**示例文件**，不代表导出真实运营数据。地区只筛选样例，演示身份不构成权限边界；AI输入输出都是预先编写的样例。

界面复用Element Plus，图表复用ECharts；从已锁定plus-ui Vue分支裁剪Pagination/RightToolbar并保留原始快照和许可证。家风外壳与业务页为定制实现，未引入完整plus-ui鉴权/HTTP模块或WarmFlow引擎。后台是独立Web端，手机宽度检查不构成微信小程序运行验收。

## 2026-09-27 私人记录汇总与搜索服务

工作台增加授权地区的诵读/家庭约定数量汇总；不提供私人标题、正文或录音明细。会员主动投稿后仍在既有媒体管理中审核。媒体类别选择「诵读」、类型选择「音频」，分别编辑发布中文或英文，前台故事列表读取已发布条目。

「系统设置 → 搜索服务」显示可用状态、目录/索引版本、待同步数量及最近错误。区域运营可读，全国管理员可重建；索引重建保留原始业务数据。故障恢复和重建证据见[本轮验证](../verification/records-search-2026-09-27.md)。
