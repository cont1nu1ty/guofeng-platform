# 首页与内容目录的后台联动

2026-09-26。来源为原 PDF 第4页 §4.1、第5–6页 §4.5–4.9、第6–7页 §5.4–5.5，另含投稿客服及站内订阅的实际接入需要。本文说明本机 HTTP 模式；不将云端生产能力或默认 demo 模式计为完成。

## 现在从哪里操作

打开 [管理后台](http://127.0.0.1:18080/admin/#/content)，进入“内容与资讯”。保留原有13个主导航，在本页按页签管理：

- 资讯文章：四个内容专区，公告、政策解读、行业动态、活动报道、榜样人物等分类；中文、英文分别保存与发布。
- 首页轮播：全国政策通知、征稿公告、年度盛典、典籍首发、研学活动、廉政课堂六类。配置地区、语言、文案、可选封面、排序、展示起止时间和目标页面/记录。
- 媒体与素材：上传 MP4、MP3、WAV 及封面，编辑文字稿、合集、展示类别，审核会员投稿并发布或退回。
- 传习阵地：宗祠名人馆、文明实践中心、廉政教育基地三类；地址、开放时间、导览、联系与参观须知；关联已公开活动进入报名流程。
- 名人馆档案：人物、生平、主题、家训、阅读文字及来源。可填写合法外部全景链接，系统不生成 VR 实景。
- 首页栏目：全国管理员控制入口、专区、资讯、作品、阵地、统计六个区块的顺序和显示开关。
- 人工咨询：对应区域运营查看问题单，回复或关闭；会员在原咨询入口查看真实处理结果。

文章中的旧 Banner 分类只保留历史兼容；新增首页推荐统一在“首页轮播”页签维护。

新目录保存为草稿，确认后单独发布。修改已发布目录会转回草稿，避免未确认编辑立即公开。文章仍沿用原来的编辑/发布流程。轮播目标未发布时不能发布轮播；目标撤回、轮播尚未到期或已过期时，用户端不显示该轮播。删除或清空历史业务数据不是本轮操作的一部分。

## 网页端体验

1. 首页点击轮播圆点，可以检查六类跳转；切换语言或地区仅查看对应已发布版本，HTTP空数据不补固定演示。
2. 首页统计读取本机稿件总数、不同投稿作者数、实际出现的投稿地区数。它们来自数据库，但当前记录仍是虚构展示数据。
3. 短视频展播的目录、播放来源和文字稿来自后台。登录 `member_zj` 后可见一条待审核、一条已退回投稿；退回项可以保留编号修改重投。视频/朗诵文件先上传私有存储，再提交审核；公开展播需运营发布。
4. 阵地页可查看三类场馆与公开活动关联；当前场馆均为虚构样例，不启用真实出行导航。新增真实记录填写完整坐标后才可尝试平台位置接口，地图供应商与微信真机能力尚未验收。
5. 名人馆从后台读取已发布档案；未发布资料不进入页面和公开搜索。当前新增人物均为原创虚构展示档案，明确标注来源。
6. 资讯“我的订阅”保存到登录账号。开启即时站内更新后，运营发布符合订阅分类与地区的资讯，会创建站内消息。消息跳到对应资讯；每日/每周汇总和微信推送未启用。
7. 投稿页展开“投稿客服与常见问题”，提交问题单，后台回复后回到此处查看。关键词 FAQ 仍是本地帮助，不称 AI 回答。

## 增量场景与数据保留

新增10条轮播（6条中文当前展示、1条独立英文、1条未来排期、1条过期、1条草稿）、7条媒体（4条公开含英文、1条编辑稿、2条会员待审/退回）、4条阵地（含英文版）、3条人物档案（2公开、1草稿）、2条资讯及2条咨询。

素材复用项目已有原创静音文字动画，上传到本项目私有 S3；没有盗用实际盛典、机构活动或真人录音。虚构数据不是正式政策、活动排期、荣誉或实际运营指标。

本轮开始前备份：`deploy/backups/20260926T034513Z-e4d5`（含本地密钥，仅本机保存）。演示分支的 `./deploy/dev seed-catalog` 只增量安装缺失场景，已完成记录不覆盖，用户编辑得以保留；main 不包含该专用种子脚本及数据，缺包时提前拒绝。记录 ID 与文件校验和位于 Git 忽略的 `deploy/.local/jiafeng-dev-catalog-manifest.json`；原展示数据重置命令今后会在基础场景后追加这些目录，但本轮没有重新执行重置。

演示数据分支新增统一 `./deploy/dev seed-demo`：首次导入同时包含基础场景和本页目录。新安装将检查点保存在数据库，本地清单只是可丢弃的副本；完整导入后重复执行不覆盖用户编辑。旧环境的本地清单不自动充当数据库安装证明，已有目录但无新标记时会安全拒绝再次导入，原页面和内容仍可使用。操作和旧环境边界见[部署说明](../../deploy/README.md#显式导入演示数据)。

## 明确保留的边界

- MP4/MP3/WAV 最大50MiB；图片最大10MiB；稿件仍限图片/PDF/Word、每个10MiB。浏览器录音常为 WebM/M4A，当前需用户提供受支持的文件，没有自动转码。
- 公开素材每次请求先检查发布引用，再跳转五分钟签名链接；下架阻止新签发，已经发出的签名可能在余下五分钟内继续有效。存储桶保持私有。
- 没有模型推理、OCR、自动字幕、实时直播、专业TTS、正式签章/证书、支付物流、微信正式登录或订阅推送。相关预置创作界面仍明确为样例。
- 全局搜索覆盖当前载入的公开目录及本人可见业务，不是全国容量搜索引擎。时间排序、独立语言记录、媒体文件白名单等为本轮必要设计细化，PDF没有规定其全部技术字段。

验收见[本轮验证](../verification/catalog-2026-09-26.md)，用户端完整状态仍由[统一状态文档](user-status.md)维护。
