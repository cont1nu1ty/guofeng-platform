## 重建与恢复

首次在空业务环境导入时，先运行 `./deploy/dev up`，再显式执行 `./deploy/dev seed-demo`。默认启动不生成演示内容；统一导入包括本手册的基础场景和[首页与目录场景](catalog-management.md)。完整导入后重复调用会跳过，保留之后的编辑；具体分支部署、数据包和中断恢复见[部署说明](../../deploy/README.md#显式导入演示数据)。

在项目根目录执行 `./deploy/dev reset-demo`，会先备份，再清理本项目当前业务和会话，重新生成这套数据。该操作会清除上一次展示过程中新增或修改的业务记录；重建后需重新登录。它不导入浏览器中的旧 Mock 数据，也不处理其他项目的数据。

停止服务、备份和恢复到独立环境的方法见 [部署说明](../../deploy/README.md)。本轮数据检查与网页验证从 [验证索引](../verification/README.md) 进入；本说明不将网页展示等同于微信真机、正式微信登录、模型推理或全国容量验收。
