## 2026-10-13 AI 应用用户端接入

HTTP 模式已将家书、家训、润色、知识问答、平台客服、内容自检与手稿识别接到异步 AI 任务接口。前端不包含模型密钥；模型和是否外部 API 由服务状态返回。开发外部 API 模式在对话/OCR处说明，用户发送的内容由服务端交给所配置的模型。默认 demo 仍使用明确标注的规则和预设。

- **对话与来源**：沿用 `ConversationPanel`，支持上下文提问、排队/处理中状态、失败保留输入、同幂等键重试、停止等待与本人任务历史恢复。停止等待不取消服务端任务。显示模型和引用片段，仅允许站内公开内容引用跳转；审核提示及相似段落作为人工辅助，不代表审核通过或抄袭认定。
- **云端存档与草稿**：确认使用后进入现有编辑区，可复制、按本人账号存档或创建新投稿草稿。记录区分模型结果与旧样例，保留任务/模型/引用信息。普通草稿需明确替换；带原稿编号的退修稿仍禁止覆盖，新稿不自动确认版权或提交。
- **OCR**：助手“手稿校对”及投稿附件区“手稿识别与校对”进入同一流程。JPG/PNG/PDF经`manuscript`用途上传（单个10MiB），创建识别任务；原图预览/重新授权打开原件、待校文本修改、明确采用后存档或转稿。识别失败保留文件和输入；从投稿进入前必须成功保存当前云草稿。碑文、模糊件、生僻字识别效果需项目样本单列评测。
- **相关入口**：投稿“寻找创作灵感”使用真实任务；投稿客服从AI多轮回答转入原有人工作单并可查看运营回复；典籍阅读和名人馆提供带作品/人物名称的问题入口。
- **隔离与边界**：切换账号清空页内结果并丢弃迟到响应；私人任务不写入公共目录。HTTP模式隐藏未接入的短剧生成，服务失败不回落为预设成功。语音合成、图文视频、完整格律、推荐与运营预测仍未由这次前端接入完成。

整合前 AI V005 分支实际执行：`npm run typecheck`通过；`npm test`为19个文件、135项通过（新增14项AI任务与边界测试）；`VITE_DATA_MODE=http npm run build:h5`和`VITE_DATA_MODE=http npm run build:mp-weixin`通过。微信主包1,574,843B，余量522,309B；构建检查确认两份唯一内联字体且无重复WOFF。H5仍有原有字体路径构建时未解析警告，资源实际显示须按页面验证。这些计数与包体属于整合前源码。桌面/手机网页、真实模型与OCR实联由[原 AI 验证](../verification/ai-2026-10-13.md)单列；整合后的测试以[本次记录](../verification/ai-sync-2026-10-13.md)为准；此处没有新增微信真机或模型质量验收结论。统一入口见[验证索引](../verification/README.md)。

## 判定方式与证据

- **已完成（界面）**：当前展示或本机演示交互已存在；只认可表内写明的范围，不表示对应生产业务已经上线。
- **部分完成**：同一条前端要求已有入口或部分交互，但仍缺可见流程、页面或状态。
- **待实现**：没有该项对应的完整前端交互；相似卡片或参数预览不算完成。
- **待验证**：代码已有实现或降级，但缺目标终端、可访问性、双语或性能证据。它不等于已知失败。
- **已接入（试点HTTP）**：使用本次真实接口，完成范围和实际验收按上节记录，不等于正式生产运营。
- **服务待接入**：单独说明真实登录、云存储、模型、消息、订单等依赖，不将其混成“所有前端都没完成”。
