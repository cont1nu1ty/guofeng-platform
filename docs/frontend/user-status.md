## 2026-09-27 个人记录与搜索增量

HTTP 模式的诵读打卡、家庭约定现存入本人账号。录音原文件经服务端受限转换为 MP3 后存入私有 S3，记录元信息进入 MySQL；个人中心支持回放、删除与主动投稿。约定按本人＋人物唯一，支持版本冲突保稿，人物下架后仍保留本人历史。后台仅返回授权地区汇总，私人标题、正文、文件与操作明细不进入运营工作区或公开搜索。

音频故事改读后台已发布的音频诵读目录，支持独立语言发布及下架。全站搜索改为独立 Elasticsearch 接口，按九类公开内容、语言、地区分页；索引更新或服务故障显示重试，不回退本机结果。演示分支的新增样例通过显式 `seed-demo-records` 追加；main 不包含可导入数据包。旧设备记录不会自动归属当前账号。

上述功能在演示分支实现时，类型检查、121项单元测试、HTTP H5和微信构建已通过；这些历史运行结果不代表本次 main 拆分后重新执行。真实容器、录音与浏览器证据统一见[个人记录与搜索验证](../verification/records-search-2026-09-27.md)。微信真机、物理麦克风和全国容量需要各自的实测证据；浏览器注入测试音源不当作物理麦克风验收。

## 判定方式与证据

- **已完成（界面）**：当前展示或本机演示交互已存在；只认可表内写明的范围，不表示对应生产业务已经上线。
- **部分完成**：同一条前端要求已有入口或部分交互，但仍缺可见流程、页面或状态。
- **待实现**：没有该项对应的完整前端交互；相似卡片或参数预览不算完成。
- **待验证**：代码已有实现或降级，但缺目标终端、可访问性、双语或性能证据。它不等于已知失败。
- **已接入（试点HTTP）**：使用本次真实接口，完成范围和实际验收按上节记录，不等于正式生产运营。
- **服务待接入**：单独说明真实登录、云存储、模型、消息、订单等依赖，不将其混成“所有前端都没完成”。

## 这轮不混入前端待办的事项

试点已接真实账号、上传、云草稿、投稿及相关基础业务接口。微信登录/实名、正式版权存证、证书签发、订单履约、AI模型与知识库、地区物理分库、百万用户容量及完整安全治理仍未完成。这些是 [全平台接入与交付差距](../engineering/integration-gaps.md)，不是要求本轮把用户端页面全部推倒重做。

本文件不输出单一“完成百分比”：一个入口、一个本机流程和一个生产服务的验收量不同。下一轮优先顺序由 [用户端前端待办](user-backlog.md) 维护。
