# AI 应用接入与维护

更新：2026-10-13。对应 PDF 的 AI 助手、知识服务、OCR、审核辅助，以及用户本轮确认的第一批和第二批。原 PDF 的私有部署目标保留；本轮用户明确允许开发阶段使用智谱 API，后续切换本地模型 URL。当前配置不是“已完成本地模型部署”。整合前 AI V005 的模型与网页实联见[原验证](../verification/ai-2026-10-13.md)，与非 AI V014 合并后的源码检查见[本次整合记录](../verification/ai-sync-2026-10-13.md)，不把原实联当作整合版已部署。

## 已接业务

用户端「助手」提供家训建议、家书创作、润色、知识问答、平台客服、OCR 校对和内容检查。典籍阅读、人物详情可带问题进入知识问答；客服可转已有人工咨询。模型输出需用户编辑确认后存档或用于稿件，不能自动提交、发布或承诺获奖。历史设备样例继续标为示例，不伪装成模型回答。

OCR 使用本人上传的 PNG/JPEG/PDF，后端从私有 S3 读取原文件，经识别返回可编辑正文。历史识别任务保存在本人账号中，可再次校对；编辑确认后用于写作/投稿。当前开发调用 GLM-OCR，不承诺古籍、竖排、手写或表格的准确率，原图和人工核对仍是必要步骤。

后台「AI 运维」显示模型配置状态、开发外部 API 标识、资料索引范围和实际调用记录。上传资料后仍是未索引，需要选择中文/英文及“用户端可检索”或“内部运营”并明确建立索引。仅授权运营可处理本地区资料，撤回后停止检索，也停止展示引用它的旧回答与存档。

「投稿作品 → 稿件详情 → AI 辅助」读取服务器当前稿件版本，生成审核建议或摘要、主题词、风险原文和相似内容证据。相似度是授权稿件中三字符片段的 Dice 重合率，**不是语义查重准确率或抄袭结论**。分析不更改稿件状态、分数或录用结果；稿件变化后隐藏旧分析并要求重新生成。

## 服务与数据

业务认证、所有权、地区权限、幂等和版本检查留在若依家风模块。`jf_ai_task` 保存本人请求、执行状态和结果；当前以 MySQL V015 增量迁移加入 AI 表，保留非 AI V005–V014。旧 AI 分支曾使用 V005，兼容时只接受其已知校验值及匹配的已记录迁移历史，其他异常继续拒绝升级；不能直接覆盖旧迁移历史或把历史验证中的 V005 改称 V015。操作日志只记任务、模式、模型和实际 usage 等运行信息，不复制私人正文或文件信息。全国管理账号也不能直接阅读会员的私人任务详情。

`apps/ai` 是内网 FastAPI 适配器，复用 FastAPI、Uvicorn、pypdf；不增加第二套账号或工作流系统。Java 经内部随机密钥调用它；浏览器不能直接访问，也不会取得模型密钥。文本和视觉模型支持兼容 `/chat/completions` 的 URL；开发智谱 OCR 使用 `/layout_parsing`。没有绑定模型 SDK 或引入模型权重。

公开目录问答复用现有 Elasticsearch，并重新核对当前发布版本。上传知识资料由受限子进程解析 PDF/DOCX；扫描 PDF 转 OCR。提取文本分块保存到 `jf_ai_chunk`，使用 MySQL ngram FULLTEXT 检索，按语言和公开/内部地区权限过滤。现阶段是词面检索增强生成，未引入向量模型、向量库或重排模型。回复显示检索依据供核对，不保证模型每条事实正确。

资料片段、历史消息和 OCR 文本作为不可信输入，不能触发工具或业务操作。引用在生成后、读取时和存档展示时核对版本与权限；已撤回、下架或修改的资料使旧结果失效。私人约定、打卡、未公开原稿不会自动进入公开知识库；模型审核只使用当前授权稿件。

任务由数据库队列驱动，模型网络调用在业务事务之外。两个 worker；每账号最多 3 个在途任务、每小时 60 次，整体排队最多 50 个。运行超过 4 分钟/排队超过 20 分钟显式失败，不自动重复收费调用。客户端网络重试复用幂等键，终态失败可由用户主动重试。文件 10MiB、输入和上下文长度、解析进程 CPU/内存/时长、响应长度均有限制；供应商错误只返回固定安全消息。

## 运维和后续

配置项、开发 API 和本地 URL 示例见[部署说明](../../deploy/README.md)。新环境 AI 默认关闭；进程健康只表明适配器存活，页面“已配置”也不证明供应商账户有效，需要实际任务验证。MySQL 和 S3 继续作为备份基线；AI 任务和知识分块随数据库备份，运行中任务恢复后按超时规则明确失败。

后续仍需本地模型服务的实际兼容验证、固定评测集与人工质量标注、提示注入对抗集、敏感内容运营规范、成本监控与生产容量验证。古籍专业校勘、严格格律校验、语音合成/配音、短剧/视频生成、个性推荐和运营预测不包含在这两批完成范围。未执行的微信真机、真实手写识别准确率及全国容量不能以构建或少量请求替代。
