## 本轮实现

本轮继续补齐**用户端界面与本机操作**，保留已有布局、指定红金墨米白配色和实际思源字体加载；运营后台没有扩展。

- 调整右上角“家”字头像的垂直位置；投稿“寻找创作灵感”改为当前页的可折叠面板，桌面并排、小屏内联，支持复制或确认追加，保留原稿；个人中心的长摘抄可点开阅读完整正文与感想。
- 个人中心提供演示登录、认证填写、未认证／审核中／通过／失败与修改重提状态。作品、课程、活动证书可生成带演示水印的 PNG；H5 发起实际下载，微信有生成图片、保存相册与权限失败处理。
- 投稿使用 Uni-app 富文本 editor，支持真实加粗、斜体、下划线、标题和列表；草稿、预览及重投保留白名单 Delta 格式。补充海外国家城市、按标点计句计字的诗词参考、常见问题、本机会话和转人工状态预览。
- 全国选择覆盖 34 个省级地区及海外；全局搜索展示作品、资讯、典籍、活动、课堂、视频、名人馆、文创、阵地 9 类完整结果，支持类别／地区筛选与空结果。资讯可订阅、取消、查看订阅内容，并保存提醒频率和免打扰偏好。
- 传习新增中英有声故事、录音／选择音频、试听、诵读打卡和本机记录；短视频可选择本地文件、预览并记录投稿，补分镜、字幕、配音参数及直播三种状态。回放支持实际文件缓存、从缓存播放及删除，单个回放缓存不等于全站离线可用。
- 名人馆新增可拖动空间示意、家训画布描摹、图片预览／保存、知识问答与中英讲解音频。空间由原创平面元素组成，不将它称为真实 720° VR 或实景扫描。
- 助手扩为家书、家训、润色、手稿校对、使用帮助、家风知识问答、内容审核样例、短剧分镜 8 类预设。支持复制、存档与恢复；创作结果可安全转为新稿，知识和审核资料不能作为作品转稿。
- 保留已有轮播、四专题、课程测验、预约签到、六级模拟评审、同编号重投、典藏横竖排／朗读／释义／摘抄、公益及定制记录等操作。新增独立搜索视图后共 15 个业务视图。

推荐从 **投稿 → 就地灵感与富文本 → 个人中心认证／长摘抄／证书 → 搜索与资讯订阅 → 传习音频 → 视频与名人馆 → 八类助手** 检查这一轮变化。完整操作与平台差异见 [演示说明](docs/05-demo-guide.md)，实际测试结果单列在 [验证记录](docs/07-validation.md)。

业务记录只在当前设备，没有真实微信登录、实名核验、投稿入库、人工客服接单、AI 推理、支付或正式证书签发。录音和选取文件使用终端能力，播放和导出处理实际文件；生成式视频、OCR、审核及直播仍明确标为预设或状态演示。微信相册、录音、字体、竖排和完整操作仍需真机验证。

初始版本及各轮检查点见 [迭代与回退](docs/08-iteration-record.md)。本轮版本为 `v0.5.1-chat-carousel`，增加 `pkg-content` 内容分包和 AppShell 插槽，使内容页与公共框架分离，给后续扩展留下入口。

## 启动与检查

建议 Node.js 22 LTS 或更高的兼容版本（引入底座要求至少 20.19）；本次环境为 Node.js 26.9.0。依赖已在当前机器安装；其他机器用锁文件安装：

```bash
cd apps/miniapp
npm ci
npm run dev:h5
```

```bash
npm run typecheck
npm run format:check
npm test
npm run build:h5
npm run build:mp-weixin
```

H5 构建产物：`apps/miniapp/dist/build/h5`。微信产物：`apps/miniapp/dist/build/mp-weixin`。

### 微信开发者工具预览

在 `apps/miniapp` 目录运行并保持终端开启：

```bash
npm run dev:mp-weixin
```

等待 `Build complete. Watching for changes...` 后，在微信开发者工具中导入 **`apps/miniapp/dist/dev/mp-weixin`**。所选目录内应直接看到 `app.json`、`app.js`、`project.config.json` 和 `pages/`。不要选择 `dist/dev`、`dist` 或 `apps/miniapp` 源码目录；这些目录没有可直接运行的小程序入口。

若只查看一次性构建，运行 `npm run build:mp-weixin` 后导入 **`apps/miniapp/dist/build/mp-weixin`**。开发命令只更新 `dev`，构建命令只更新 `build`。

AppID 的持久配置入口是 `apps/miniapp/src/manifest.json` 中的 `mp-weixin.appid`，不要只修改 `dist` 内的配置（再次编译会覆盖）。已将本机开发者工具项目中填写的 AppID 同步到该入口；需确保当前登录微信账号有该小程序的开发权限。

如果仍为空白：检查「详情 → 本地设置」中的项目目录和小程序目录，再使用普通编译模式、入口 `pages/index/index`，查看「调试器 → Console」第一条红色报错。无需执行「构建 npm」，当前产物已由 Uni-app 打包依赖。不要为此清空存储，以免丢失演示草稿。

已修复全局样式中 H5 专用通配选择器导致的微信 WXSS 编译错误；开发及构建产物的原生样式编译检查通过，用户已确认微信模拟器首页显示。尚未完成微信端全部交互和真机验证。**编译通过不代表满足文档中的微信 2.10.0 兼容要求**；Vue 3/Wot UI 和该旧版本要求需专项评估后明确最低基础库，见选型文档。

## 项目结构

```text
jiafeng-platform/
  apps/miniapp/
    src/components/         核心业务视图与共用界面组件
    src/composables/        界面状态、导航与存储适配
    src/domain/             DTO、示例数据、纯 TS 仓库和校验
    src/pages/              主包首页与核心业务入口
    src/pkg-content/        资讯、课堂、传习、场馆、媒体、名人馆、文创内容分包
      components/           内容视图及其专属组件
      static/               内容分包的音视频素材
    src/vendor/             H5 富文本所用 Quill 1.3.7 与原始许可证
    src/styles/             主题、响应式样式与本地图标字体
    tests/                  领域状态、评审、存档与文创校验测试
    package-lock.json       可重复安装的精确依赖锁定
  contracts/openapi.yaml    后端接口草案
  docs/                     需求、待办、选型、架构、演示与验证
  licenses/                 已复用项目的原始许可
  source-lock.json          上游提交、实际引入范围与改动记录
```

首页与核心业务使用主包页面；七类内容视图由 `pkg-content/pages/index` 挂载。`AppShell` 保留公共框架，通过插槽承载业务组件；旧 `pages/explore/index?screen=...` 内容链接自动转到分包入口，保留详情参数。详情跳转保留上页并支持系统返回，一级栏目切换重新建立页面栈。分包构建不等于微信真机容量或性能验收；正式上线前仍需验证布局、基础库、包体与无障碍。

## 复用与后续开发原则

前端采用 Wot Starter 的工程基础进行裁剪，实际使用 Wot UI 组件，保留 MIT 文本与锁定版本。富文本复用 Uni-app editor；H5 所需 Quill 1.3.7 随源码交付并保留 BSD 许可证，不在运行时依赖公共 CDN。后端建议先验证 **RuoYi-Vue-Plus + 匹配 plus-ui Vue 分支**；若复杂工作流和商城提前成为核心，可改选芋道配套体系。不要把两套后台整仓拼装在一起。

先确认投稿→审核→公示的一条业务闭环；随后用 `contracts/` 的契约接入服务层。前端 `region` 只用于内容筛选，后台必须从已认证身份确定租户和数据源。省级物理隔离、全国总库同步与私有 AI 都需要独立技术验证和验收，现有模板不会自动解决。
